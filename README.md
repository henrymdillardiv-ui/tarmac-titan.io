# Tarmac Titan — The Future Sim

Tarmac Titan is a high-fidelity vehicle simulator built for car and flight-enthusiasts. It focuses on realistic controls, polished visuals, and flexible customization. This repository contains the project source and assets; the project is a work in progress.

## Features

- Realistic vehicle behavior and controls
- High-quality graphics and visual effects
- Extensive customization options for vehicles and environments
- Modular structure for easy development and extension

## Development

This project currently has a simple layout:

- `assets/` — media and static assets
- `server/` — server code (if applicable)

To preview the project locally (for example, if it's a static site), you can serve the repository root with a static server. Example using Node.js:

```bash
# from the project root
npx http-server . -p 8080
# then open http://localhost:8080 in your browser
```

If the project requires a backend, check the `server/` folder for setup instructions (the server folder may be empty or under development).
